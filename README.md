## Run the project
1. Install Python 3.10+ (or a version supported by the project).
2. Open the project folder in VS Code.
3. In a terminal, install dependencies: `pip install -r requirements.txt`
4. Run: `python app.py`
5. Open `http://127.0.0.1:5000` in a browser.
6. For tests, follow the commands in the repository README or `run_all.py` if included.
