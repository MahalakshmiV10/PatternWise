# PatternWise — Quiz and Answer Key

## Questions
1. Which pattern is intended to provide one shared instance?
2. Which pattern delegates the decision of which concrete product to create?
3. Which pattern is useful for step-by-step construction of a complex object?
4. Which pattern converts one interface into another expected interface?
5. Which pattern adds behavior by wrapping an existing object?
6. Which pattern provides a simplified entry point to a subsystem?
7. Which pattern allows an algorithm to be swapped independently?
8. Which pattern notifies multiple subscribers when a subject changes?
9. Give one potential drawback of Singleton.
10. Why should a developer avoid using a pattern when the problem does not need it?

## Answer key
1. Singleton.
2. Factory Method.
3. Builder.
4. Adapter.
5. Decorator.
6. Facade.
7. Strategy.
8. Observer.
9. Shared global state can complicate tests and concurrency.
10. Unnecessary abstractions increase complexity and make code harder to maintain.
