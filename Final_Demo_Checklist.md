# PatternWise — Final Demo Checklist

## Before the demo
- [ ] Pull the final code from GitHub.
- [ ] Install requirements and run the test suite.
- [ ] Start the Flask app and confirm the local URL opens.
- [ ] Close unrelated tabs and keep the browser zoom readable.
- [ ] Keep a backup screenshot or short recording in case the live environment fails.

## Suggested 5–7 minute flow
1. **Introduction (30 sec):** State the goal of PatternWise.
2. **Home page (45 sec):** Show navigation and how patterns are organized.
3. **Pattern walkthrough (3 min):** Explain the problem and example for Singleton, Factory Method, Builder, Adapter, Decorator, Facade, Strategy, and Observer briefly.
4. **Quiz / learning interaction (45 sec):** Demonstrate it if available in the submitted version.
5. **Technical overview (45 sec):** Mention Flask, HTML/CSS/templates, project structure, and GitHub.
6. **Testing (30 sec):** Show the real test command and current output.
7. **Conclusion (20 sec):** Summarize what was learned and possible future improvements.

## Closing statement
“PatternWise is an interactive learning guide that introduces eight common software design patterns through concise explanations and examples. It is intended to help learners connect design problems with reusable solutions.”
