# PatternWise — Prompt Library

This is a reusable prompt log/template for documenting AI-assisted work. Keep only prompts that accurately reflect what was actually used during development.

1. **Project planning:** “Help me plan an educational web application that teaches software design patterns, with a clear scope, pages, and learning outcomes.”
2. **Pattern explanations:** “Explain Singleton, Factory Method, Builder, Adapter, Decorator, Facade, Strategy, and Observer using intent, use cases, benefits, drawbacks, and a small illustrative example.”
3. **Flask structure:** “Suggest a simple Flask project structure for an educational site, separating routes, templates, static assets, and pattern examples.”
4. **UI review:** “Review this educational page layout for readability, consistent navigation, responsive behavior, and accessibility.”
5. **Testing:** “Create test cases for the routes and pattern examples shown in this code. Do not claim tests pass unless the tests are executed.”
6. **Debugging:** “Given this traceback and relevant code, identify the likely cause and suggest the smallest safe fix.”
7. **Documentation:** “Draft a README with setup instructions, dependencies, run steps, project features, and limitations.”
8. **Submission review:** “Compare the project files with this final-submission checklist and identify missing items without assuming files exist.”

**Academic note:** Adapt this list to match the actual prompts used and your institution's AI-use disclosure rules.
